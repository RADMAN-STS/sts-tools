If mapped, a one-way lane's final mileage gets doubled when marked "Round Trip". If a lane already has stops that loop back to the origin, the stop chain covers the full trip already and doesn't get doubled again.

For multi-stop lanes, map each Stop column (expects a combined cell like "COLUMBIA CITY, IN, 46725, USA"). Mileage becomes the full chain: Origin → Stop 1 → Stop 2 → ... → Destination, added leg by leg. Blank stop cells are skipped.
