4Pick the sheet, header row, and columns — RFP lanes

Required

Optional (recommended)

If Equipment Type is mapped on both sides, matching groups equipment by its core type — Reefer, Dry Van/Closed Van/Container, Heated/Heater, Sprinter, Flatbed — ignoring size and axle prefixes, so "17 Sprinter" connects to "Sprinter" and "53 Heater" connects to "Heated". A Reefer lane only pulls a previous Reefer quote, a Dry Van lane only pulls a previous Dry Van quote, and so on. If no quote exists for the exact equipment type, the closest available quote on that lane is used instead and flagged "different equipment, verify." The equipment type in the RFP is left exactly as it was either way.

5Confirm the customer

Only ACTIVE quotes for this customer will be used — a match on lane alone isn't enough, since the same origin/destination can belong to more than one customer in your quote history.

6Results

The downloaded file is identical to the RFP you uploaded — same sheets, same formatting, same every other column. Four columns are added to the end of the lane sheet: Previous Quote #, Previous Rate, Previous Currency, and Previous Quote Note.
